1 Mean (x̄)

The mean is the "fair share": add everything up, then divide by how many there are.

A · Raw data

Formulax̄ = Σx ÷ N
  1. Add them all up: Σx = 12 + 8 + 5 + 5 + 9 + 18 + 12 = 69
  2. Count the numbers: N = 7
  3. Substitute into the formula:x̄ = 69 ÷ 7 = 9.857…

Mean ≈ 9.86 thousand views

B · Frequency table

Formulax̄ = Σfx ÷ Σf
  1. Multiply each value by its frequency (f × x):
    xffx
    2816
    31236
    41560
    5525
    Σ40137
  2. Substitute into the formula:x̄ = 137 ÷ 40 = 3.425

Mean ≈ 3.43 cups per week

C · Grouped data

Formulax̄ = Σfx ÷ Σfx = (lower limit + upper limit) ÷ 2x = class midpoint

Mean = 5.15 hours per day

2 Mode

The mode is the value that appears most often. A set of data can have more than one mode.

A · Raw data

RuleMode = the value that appears most often
  1. Sort the numbers: 5, 5, 8, 9, 12, 12, 18
  2. Count each one: 5 → 2 times, 12 → 2 times, the others → 1 time

Mode = 5 and 12 thousand views (two modes)

B · Frequency table

RuleMode = the value with the highest f
  1. Look down the frequency column: 8, 12, 15, 5
  2. The highest frequency is 15, for 4 cups

Mode = 4 cups per week

C · Grouped data

FormulaMode = L + (d₁ ÷ (d₁ + d₂)) × c
  1. Modal class = the class with the highest frequency = 5 – 6 (f = 18)
  2. L = lower boundary of 5 – 6 = 4.5
    Classes are 1–2, 3–4, 5–6…, so the boundaries are halfway between: 4.5 and 6.5.
  3. d₁ = 18 − 8 = 10 (difference with the class before)
    d₂ = 18 − 7 = 11 (difference with the class after)
    c = 6.5 − 4.5 = 2 (class width)
  4. Substitute into the formula:Mode = 4.5 + (10 ÷ (10 + 11)) × 2 = 4.5 + 0.952 = 5.452

Mode ≈ 5.45 hours per day

3 Median

The median is the middle value when the data is in order.

A · Raw data

FormulaPosition of median = (N + 1) ÷ 2
  1. Sort: 5, 5, 8, 9, 12, 12, 18
  2. Substitute into the formula:Position = (7 + 1) ÷ 2 = 4So the median is the 4th value.

Median = 9 thousand views

B · Frequency table

FormulaPosition of median = (N + 1) ÷ 2N = Σf
  1. Substitute into the formula:Position = (40 + 1) ÷ 2 = 20.5So the median is halfway between the 20th and 21st values.
  2. Add a cumulative frequency column:
    xfCumulative f
    288 (values 1–8)
    31220 (values 9–20)
    41535 (values 21–35)
    5540 (values 36–40)
  3. 20th value = 3, 21st value = 4
  4. Take the middle of the two:Median = (3 + 4) ÷ 2 = 3.5

Median = 3.5 cups per week

C · Grouped data

FormulaMedian = L + ((N/2 − F) ÷ fₘ) × c
  1. Find the middle position:N/2 = 40/2 = 20
  2. Cumulative frequency: 5, 13, 31, 38, 40. The 20th value is in class 5 – 6
  3. L = 4.5 (lower boundary)
    F = 13 (cumulative f before the class)
    fₘ = 18 (frequency of the class)
    c = 2 (class width)
  4. Substitute into the formula:Median = 4.5 + ((20 − 13) ÷ 18) × 2 = 4.5 + 0.778 = 5.278

Median ≈ 5.28 hours per day

4 Range

The range shows how spread out the data is: largest value minus smallest value. For grouped data, use the class midpoints.

A · Raw data

FormulaRange = Largest − Smallest
  1. Largest value 18, smallest value 5
  2. Substitute into the formula:Range = 18 − 5 = 13

Range = 13 thousand views

B · Frequency table

FormulaRange = Largest − Smallest
  1. Largest value 5, smallest value 2
  2. Substitute into the formula:Range = 5 − 2 = 3

Range = 3 cups

C · Grouped data

FormulaRange = midpoint of last class − midpoint of first class
  1. Midpoint of the last class (9 – 10):(9 + 10) ÷ 2 = 9.5
  2. Midpoint of the first class (1 – 2):(1 + 2) ÷ 2 = 1.5
  3. Substitute into the formula:Range = 9.5 − 1.5 = 8

Range = 8 hours

5 Variance (σ²) & standard deviation (σ)

These measure how far, on average, the data is from the mean. Find the variance first, then take its square root to get the standard deviation.

💡 Keep the full mean (for example 3.425, not 3.43) until the very last step. Rounding early makes the answer slightly wrong.

A · Raw data

Formulaσ² = Σx² ÷ N − x̄²σ = √σ²
  1. Square each value and add:Σx² = 144 + 64 + 25 + 25 + 81 + 324 + 144 = 807
  2. From Step 1: x̄ = 69 ÷ 7 and N = 7
  3. Substitute into the formula:σ² = 807 ÷ 7 − (69 ÷ 7)² = 115.286 − 97.163 = 18.12
  4. Standard deviation:σ = √18.12 = 4.257

σ² ≈ 18.12, σ ≈ 4.26 thousand views

B · Frequency table

Formulaσ² = Σfx² ÷ Σf − x̄²σ = √σ²

σ² ≈ 0.894, σ ≈ 0.95 cups
