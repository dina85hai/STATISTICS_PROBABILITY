1 Terminology of statistics

The key words used in this unit. Each one has an electrical engineering example (⚡).

Statistics
The science of collecting, organising, presenting, analysing and interpreting data to make decisions.
Studying the daily load on a substation to plan maintenance.
Data
Facts or values collected by counting or measuring. One value is called a datum or an observation.
Voltage readings from a multimeter.
Population
The whole group of items or people that we want to study.
All 10 000 resistors made by a factory in one day.
Sample
A smaller part of the population that is actually tested or measured.
40 resistors picked from the day's production for testing.
Variable
A characteristic that can take different values from one item to another.
Resistance (Ω), current (A), number of faults.
Qualitative data
Data that describes a quality or category, not a number. Also called categorical data.
Cable colour, type of motor (AC / DC), brand of circuit breaker.
Quantitative data
Data in the form of numbers that can be counted or measured. It is either discrete or continuous.
Power in watts, number of blown fuses.
Discrete data
Data that is counted. It can only take exact separate values, usually whole numbers.
Number of power trips per week: 0, 1, 2, 3…
Continuous data
Data that is measured. It can take any value in a range, including decimals.
Voltage = 239.6 V, temperature of a transformer = 65.3 °C.
Ungrouped data (raw data)
Data listed one value at a time, as it was collected, not arranged into classes.
Current readings: 2.1, 2.4, 1.9, 2.2 A.
Grouped data
Data arranged into classes (intervals) with the frequency of each class. Used when there are many values.
Resistance 95 – 99 Ω: 9 resistors.
Frequency (f)
How many times a value, or a value in a class, appears in the data.
3 motors failed in week 1, so f = 3 for that value.
Tally
Strokes used to count data quickly. Every 5th stroke crosses the previous four: |||| = 5.
Counting faulty sockets while inspecting a building.
Frequency table (frequency distribution)
A table that shows each value or class with its frequency.
Number of outages per week and how many weeks had that number.
Class (class interval)
A group of values in grouped data, such as 95 – 99.
Currents from 1.0 A to 1.4 A.
Class limits
The smallest (lower limit) and largest (upper limit) values written for a class.
For 95 – 99 Ω: lower limit 95, upper limit 99.
Class boundaries
The "true" edges of a class, halfway between one class and the next, so there are no gaps. Lower boundary = lower limit − 0.5, upper boundary = upper limit + 0.5 (for whole-number limits).
95 – 99 Ω has boundaries 94.5 and 99.5.
Class width (class size, c)
Upper boundary − lower boundary.
99.5 − 94.5 = 5 Ω.
Class midpoint (class mark, x)
The middle value of a class: (lower limit + upper limit) ÷ 2. It represents the class in calculations.
(95 + 99) ÷ 2 = 97 Ω.
Cumulative frequency (F)
The running total of frequencies: all values up to and including this value or class.
27 resistors are below 104.5 Ω.
Relative frequency
Frequency ÷ total frequency. Often written as a percentage.
15 out of 40 resistors = 0.375 = 37.5 %.
Range
Largest value − smallest value. Helps decide how many classes to use.
113 − 91 = 22 Ω.
Pie chart
A circle divided into sectors. Each sector's angle = (f ÷ Σf) × 360°.
Share of a home's monthly energy used by each appliance.
Bar chart
Separate bars with gaps, one per category or discrete value. Bar height = frequency.
Number of weeks with 0, 1, 2… outages.
Histogram
Bars with no gaps for grouped continuous data. Bars are drawn from class boundary to class boundary.
Resistance of 40 resistors in classes of 5 Ω.
Ogive
A cumulative frequency curve: cumulative frequency plotted against the upper class boundary, joined smoothly.
Reading how many resistors are below 100 Ω.

2 Discrete vs continuous data

Ask yourself: do I count it or measure it? Counted → discrete. Measured → continuous.

Discrete · counted

🔢 Exact separate values

  • Number of LEDs on a circuit board
  • Number of power outages in a month
  • Number of students who passed the Electrical Technology test
  • Number of faulty cables in a batch

You cannot have 2.5 outages, so values in between make no sense.

Continuous · measured

📏 Any value in a range

  • Voltage of a battery (e.g. 1.48 V)
  • Current drawn by a motor (e.g. 3.27 A)
  • Length of copper wire (e.g. 12.35 m)
  • Time for a capacitor to charge (e.g. 0.042 s)

The value depends only on how accurate the meter is.

  2. Draw bars of equal width with gaps between them.

Interpret: 1 outage per week is the most common (9 weeks).

Histogram · grouped continuous data

🔌 Resistance of 40 resistors

  1. x-axis: class boundaries (89.5, 94.5, …, 114.5). y-axis: frequency.
  2. Bars touch: no gaps, because the data is continuous.

Interpret: the tallest bar, 99.5 – 104.5 Ω, is the modal class.

Ogive · cumulative frequency curve

🔌 Resistance of 40 resistors

  1. Plot (upper boundary, F): (89.5, 0), (94.5, 3), (99.5, 12), (104.5, 27), (109.5, 37), (114.5, 40).
  2. Start at F = 0 on the first lower boundary, then join the points with a smooth curve.

Interpret: read across from F = 20 (half of 40) to estimate the median ≈ 102 Ω.

✓ Quick check

Answer on paper first, then check.

Question 1

Is "the number of turns on a transformer coil" discrete or continuous? Why?

Discrete: turns are counted (e.g. 250 turns), not measured.

Question 2

For the class 20 – 29 V, find the class boundaries, class width and midpoint.

Boundaries 19.5 – 29.5 V, width = 10 V, midpoint = (20 + 29) ÷ 2 = 24.5 V.

Question 3

In the pie chart, lighting uses 30 kWh out of 400 kWh. What is its sector angle?

(30 ÷ 400) × 360° = 27°.

Question 4

Using the resistor table, how many resistors are 105 Ω or more?

40 − 27 = 13 resistors (10 + 3).

Question 5

Why are there no gaps between the bars of a histogram?

The data is continuous: each class boundary is shared by two classes, so the bars touch.

Question 6

Which chart would you use to find the median resistance, and what do you plot?

An ogive: plot cumulative frequency against the upper class boundaries, then read across at Σf ÷ 2.
