Concept 1 · Counting successes

The binomial distribution

Use X ∼ Bin(n, p) when there are a fixed number of independent trials, two outcomes per trial, and the same success probability each time.

Build a probability

P(X = k) = nCk · pk · (1 − p)n − k

Box method: count the possible orders, find the probability of successes, then find the probability of failures. Multiply all three boxes.

Concept 2 · Continuous measurements

The normal distribution

A symmetric bell curve centred at the mean μ. The standard deviation σ controls its spread. We write X ∼ N(μ, σ²).

Turn a measurement into a z-score

z = (x − μ) / σ   →   P(X ≤ x) = Φ(z)

A z-score tells you how many standard deviations a value is above or below the mean.

Probability is area

For a continuous distribution, P(X = x) = 0. Therefore < and ≤ give the same probability.

Advanced · Combine the pieces

Beyond “exactly one value”

Binomial: add the right bars

For an inclusive range, add P(X = k) for each count from the lower bound to the upper bound.

P(a ≤ X ≤ b) = ∑k=a…b P(X = k)

Normal: subtract two areas

For a band between two values, subtract the left cumulative area from the right cumulative area.

P(a ≤ X ≤ b) = Φ(zb) − Φ(za)

Translate the words first

At most k: P(X ≤ k). At least k: P(X ≥ k) = 1 − P(X ≤ k − 1) for binomial counts. More than k: P(X > k) = 1 − P(X ≤ k).

For a normal variable, a right tail is P(X > x) = 1 − Φ((x − μ)/σ). The practice tab includes both tails and ranges.

A little help goes a long way.

Choose the right model

Binomial = counts. Check fixed n, independent trials, two outcomes, constant p. Sampling without replacement usually breaks independence.

Normal = measurements. Use a stated or justified normal model. A bell shape alone is not proof.

Sanity-check your answer

Every probability must be between 0 and 1. Half the normal area lies on each side of μ. The area within one σ is about 68.27%; within two, 95.45%; within three, 99.73%.

Common slips, fixed

Use σ, not σ², in the z-score. For a negative z, the left area is less than 0.5. “At least” includes the boundary count. Keep unrounded intermediate values until the final step.

Zero and boundary cases

If n = 0, then X = 0 with certainty. If p = 0, no successes occur; if p = 1, all n trials succeed. Normal σ must be positive. Negative means and negative z-scores are valid.

Remember the formulas

E(X) = np
Var(X) = np(1 − p)
nCk = n! / [k!(n − k)!]

Here, 0! = 1. The combination counts the possible arrangements of k successes.
