Concept 1 · Measures of central tendency

Mean, median and mode

Mean x

The fair share: add everything, then share it equally.

x = Σx/N

Median

The middle value once the data is sorted.

position = N + 1/2

Mode

The value that appears most often. There can be more than one, or none.

mode = most frequent value

Median trick: the cumulative f column tells you which positions each value covers. If cumulative f goes 8, 20, 35 then positions 9 to 20 all hold the second value.

Concept 2 · Measures of dispersion

Range, variance and standard deviation

Range

The quickest measure of spread.

range = largest − smallest

Variance σ²

The average of the squared distances from the mean.

σ² = Σ(x − x)²/N

Standard deviation σ

Square-root the variance to get back to the original units.

σ = √σ²

🟦 Box Method 3: the deviation squares

Each distance from the mean, (x − x), becomes the side of a real square on the picture. The variance is the average area of those squares, and σ is the side of that average square (dashed).

below the meanabove the meanaverage square (side σ)

Why square? The plain distances (x − x) always add up to 0: the negatives cancel the positives. Squaring makes every distance count.

🧮 Box Method 4: variance from a frequency table

For a frequency table, use the shortcut formula. Fill the fx, x² and fx² columns, then the totals.

σ² = Σfx²/Σf − x² Keep the full value of x in your calculator. Round only the final answer to 2 decimal places.

When data comes in classes

With grouped data we no longer know each exact value, so we use the midpoint of each class as its representative value. The answers are estimates.

Boundaries sit halfway between classes. For classes 10 – 19 and 20 – 29, the boundary is 19.5, so the class 20 – 29 has lower boundary 19.5 and width 10.

🔁 What if every value changes?

Start with the data . Multiply every value by m, then add k. Predict the new mean and standard deviation, then check the picture.

new x = m × x + k
new σ = |m| × σ Adding k slides every value: the centre moves but the spread does not. Multiplying by m stretches the spread by |m| (spread is never negative).

Tips, tricks and traps

🧠 Which average should I use?

  • Mean: when the data has no extreme values. It uses every value.
  • Median: when there are outliers, like one very high salary or a festival day.
  • Mode: for the most popular choice, like shoe size or favourite flavour. It even works for words.

✅ Sanity checks

  • The mean and median always lie between the smallest and largest value.
  • Σ(x − x) is always 0. If yours is not, recheck the mean.
  • Variance and standard deviation are never negative. If you get a negative variance, you probably squared the rounded mean or mixed up Σfx² with (Σfx)².
  • If every value is the same, the spread is 0.

⚠️ Common slips

  • Forgetting to sort before finding the median.
  • Using the median position as the answer. Position 4 means “the 4th value”, not “4”.
  • Dividing by the number of rows instead of Σf in a frequency table.
  • fx² means f × x², not (fx)².
  • Rounding x too early. Keep the full value until the last step.

🧩 Edge cases

  • Negative numbers: sort them properly, −8 is smaller than −2. Squared distances are still positive.
  • Zero: a value of 0 still counts in N. A frequency of 0 adds nothing.
  • Even N: the median is halfway between the two middle values.
  • Mode: if two values tie, both are modes. If every value appears equally often, there is no mode.
  • One value only: mean = median = mode = that value, and σ = 0.

🧘 A calm solving routine

  1. Read what is being asked: centre (average) or spread?
  2. Is the data a list, a frequency table, or grouped classes?
  3. Draw the table and fill one column at a time.
  4. Add up each column, then put the totals into the formula.
  5. Ask: does my answer make sense for this data?
