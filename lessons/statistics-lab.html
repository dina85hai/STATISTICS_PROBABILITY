Raw data, frequency table or grouped data?

Every step below solves the same three problems, just like the notes, so you can compare how the method changes for each kind of data. Type into the boxes inside the formula. A box turns green when it is right and red when it needs another look.

★The three problems

A · Raw data

🔎 How to spot it: a plain list of values. Each value counts once, so N = how many values.

✏️ Type my own list

B · Frequency table

🔎 How to spot it: each value x comes with a frequency f (how many times it appears), so multiply by f and use N = Σf.

C · Grouped data

🔎 How to spot it: the values are in classes (for example 1 – 2). We don't know the exact values, so use each class midpoint as x.

1Mean (x)

The mean is the “fair share”: add everything up, then divide by how many there are.

2Mode

The mode is the value that appears most often. A set of data can have more than one mode.

3Median

The median is the middle value when the data is in order.

4Range

The range shows how spread out the data is: largest value minus smallest value. For grouped data, use the class midpoints.

5Variance (σ²) & standard deviation (σ)

These measure how far, on average, the data is from the mean. Find the variance first, then take its square root to get the standard deviation.

💡 Keep the full mean (for example 3.425, not 3.43) until the very last step. Rounding early makes the answer slightly wrong. You can type a fraction such as 69/7 in a box.

When every value changes

🔁 What if every value changes?

Start with the data . Multiply every value by m, then add k. Predict the new mean and standard deviation, then check the picture.

new x = m × x + k
new σ = |m| × σ Adding k slides every value: the centre moves but the spread does not. Multiplying by m stretches the spread by |m| (spread is never negative).

    Tips, tricks and traps

    🧠 Which average should I use?

    • Mean: when the data has no extreme values. It uses every value.
    • Median: when there are outliers, like one very high salary or a festival day.
    • Mode: for the most popular choice, like shoe size or favourite flavour. It even works for words.

    ✅ Sanity checks

    • The mean and median always lie between the smallest and largest value.
    • Σ(x − x) is always 0. If yours is not, recheck the mean.
    • Variance and standard deviation are never negative. If you get a negative variance, you probably squared the rounded mean or mixed up Σfx² with (Σfx)².
    • If every value is the same, the spread is 0.

    ⚠️ Common slips

    • Forgetting to sort before finding the median.
    • Using the median position as the answer. Position 4 means “the 4th value”, not “4”.
    • Dividing by the number of rows instead of Σf in a frequency table.
    • fx² means f × x², not (fx)².
    • Rounding x too early. Keep the full value until the last step.

    🧩 Edge cases

    • Negative numbers: sort them properly, −8 is smaller than −2. Squared distances are still positive.
    • Zero: a value of 0 still counts in N. A frequency of 0 adds nothing.
    • Even N: the median is halfway between the two middle values.
    • Mode: if two values tie, both are modes. If every value appears equally often, there is no mode.
    • One value only: mean = median = mode = that value, and σ = 0.

    📋 Formula sheet

    x = Σx/N  or  Σfx/Σf
    σ² = Σ(x − x)²/N = Σx²/N − x²
    σ² = Σfx²/Σf − x²   ·   σ = √σ²

    Grouped data (x = class midpoint):

    Mode = L + (d₁/d₁ + d₂) × c
    Median = L + (N/2 − F/fm) × c
    Range = midpoint of last class − midpoint of first class

    4. Add up each column, then put the totals into the formula.
